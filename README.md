# 🌾 별빛 농장 (Starlight Farm)

스타듀밸리 스타일의 2D 픽셀 농장 **멀티플레이 웹 게임** 기본 골격입니다.
**Vite + TypeScript + Phaser 3** 클라이언트, **Node.js WebSocket 권한 서버**, 그리고 **모든 그래픽을 코드로 직접 생성하는 픽셀아트 파이프라인**으로 구성되어 있습니다.

## 🔐 Firebase 로그인 · 저장 (처음 한 번만 설정)

구글 계정으로 로그인하면 **진행상황(가방·골드·루미·농장 밭·외형)이 서버에 자동 저장**됩니다. 게임 서버(`npm run server`)는 그대로 쓰고, Firebase 는 로그인과 저장만 맡습니다.

1. [Firebase 콘솔](https://console.firebase.google.com) → 프로젝트 `farmar-simulater`
2. **Authentication → 로그인 방법 → Google → 사용 설정**
3. **Authentication → 설정 → 승인된 도메인**: `localhost` 는 기본 포함. 친구가 내 PC 주소(예: `192.168.0.10`)로 접속한다면 그 주소도 추가
4. **Firestore Database → 데이터베이스 만들기** (프로덕션 모드, 서울 `asia-northeast3` 추천) → 규칙 탭에 `firestore.rules` 내용 붙여넣기
5. **프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성** → 받은 JSON 을 `server/serviceAccountKey.json` 으로 저장 (깃에 올라가지 않음)

5번을 안 하면 서버가 `server/saves/*.json` 로컬 파일에 저장합니다 (서버 실행 창에 저장소 종류가 표시됨). 웹 설정값은 `shared/firebaseConfig.ts` 에 들어 있어요.

## 빠른 시작

**Windows: `start-game.bat` 더블클릭** → 패키지 설치 + 멀티플레이 서버 + 게임(http://localhost:5173)이 한 번에 실행됩니다.

또는 직접:

```bash
npm install
npm run dev          # http://localhost:5173 → "혼자 시작하기"
```

멀티플레이:

```bash
npm run server       # ws://localhost:2567 (권한 서버 + 저장)
npm run dev          # http://localhost:5173 → "구글 계정으로 시작"
```

친구는 같은 와이파이에서 `http://내PC주소:5173` 으로 접속하면 같은 PC의 서버(2567 포트)에 자동으로 연결됩니다. (다른 서버를 쓰려면 주소 뒤에 `?server=ws://주소:2567`)
테스트용으로 구글 로그인 없이 여러 창을 띄우려면: 서버를 `DEV_AUTH=1` 환경변수로 켜고 `http://localhost:5173/?dev=이름` 으로 접속.

## 📖 프롤로그: 열다섯 살, 마을의 일원이 되는 날

1. 내 방에서 눈을 뜨면 **소꿉친구**(내가 남자면 여자 '새봄', 여자면 남자 '한결')가 찾아와 "마을까지 누가 먼저 도착하는지 승부야!" 하고 먼저 달려 나가요
2. 직접 걸어서 농장 동쪽 길 끝 **별빛 마을**로 → 입구에서 **엄마**가 놓고 간 휴대폰을 건네줘요
3. **호수 왼쪽 가로등** 아래에서 기다리는 친구에게 말 걸기 → "이장님을 만나러 가자!"
4. **마을회관**의 **오 이장님**: 15살 전통, 루미 이야기, 여러 마을 소개 → 휴대폰에 **지도(M)** 추가 → 파트너 루미 선택
5. 친구는 언제나 **내게 상성이 불리한 루미**를 고르고(불→풀, 물→불, 풀→물) 방방 뛰며 **첫 대결**! (주고받다가 버프 기술만 쓰다 패배) → "칫, 분하다!" 퇴장 → 1번 도로가 열리며 모험 시작

대화는 하단 대화창 + 오른쪽 인물 일러스트(모든 인물 흉상 자동 생성), 효과음은 WebAudio 로 실시간 합성(파일 없음, Esc 메뉴에서 끄기 가능).

## 👥 함께 사는 별빛 마을 (멀티플레이)

- **구글 계정으로 시작**: 접속한 **모든 사람과 같은 세계** (마을·도로에서 서로 보이고 채팅도 공유)
- **혼자하기 (친구들만)**: 구글 로그인 후 **나만의 세계** — 우편함으로 초대한 친구만 보이고 채팅도 그 세계 안에서만. 서버에 연결할 수 없으면 이 브라우저에 자동 저장하며 혼자 진행
- **Esc 메뉴**: 계속하기 · 저장하기(오프라인) · 효과음 켜기/끄기 · **저장 초기화**(처음부터) · 타이틀로

- **처음 로그인**: 이름 + 남자/여자 외형 각 4종 중 선택 → **내 집 옷장**에서 언제든 변경
- **개인 공간**: 시작 지점인 **내 농장과 집은 나만의 공간** — 다른 유저가 보이지 않아요. **마을 광장부터 도로·바람골·가게 안은 모두가 함께** 보입니다
- **우편함 초대**: 내 농장 우편함(E) → 접속한 친구에게 🌱농장 초대 / 🏠집 초대 → 친구가 수락하면 내 농장에서 **같이 밭을 갈고 물 주고 수확**, 집에서 **식탁에 음식을 차려 같이 먹고**(4인분, 에너지 회복) 채팅
- **Tab 감정표현 휠**: Tab 을 누른 채 마우스로 방향 → 떼면 표현 (웃음·하트·놀람·궁금·슬픔·화남). 같은 공간 사람들에게 머리 위 말풍선
- **잠자기**: 침대에서 자면, 접속한 모두가 잠들었을 때 다음 날 아침 (각자 자기 농장에서 시작)
- **모든 건물 실내**: 문 앞에서 E → 내 집, 잡화점, 카페, 마을회관 연구실(한별 박사), 대장간, 이웃집 5채, 루미 쉼터, 바람골 상점, 도장(관장 세나), 풍차. 가게 주인들은 영업시간에 가게 안 카운터에 서 있어요
- 골드·출하 정산은 플레이어별, 시간·날씨는 서버 공통

## ✨ 루미 모험 (별빛 정령 수집·배틀)

농사·낚시·채광·채집을 하면서 **루미**(별빛 정령)와 함께 모험합니다. 모든 루미 이름·디자인은 이 게임 오리지널입니다.

**흐름**: 별빛 농장 → 별빛 마을 → (마을회관에서 파트너 선택) → 동쪽 **1번 도로**(풀숲·강·채석장·트레이너 4명) → **바람골 마을**(루미 센터·상점·도장·풍차)

### 시작 파트너 (마을회관 한별 박사 연구실)

| 루미 | 모티브 | 속성 | 기본 능력치 (HP/공/방/스피드) | 필드 도움 |
|---|---|---|---|---|
| 🌿 **새록** | 잎사귀 귀 강아지 | 풀 | 45 / 49 / 49 / 45 (균형형) | **농사**: 아침마다 밭 6칸 자동 물주기 |
| 💧 **찰랑** | 물방울 꼬리 고양이 | 물 | 44 / 48 / 55 / 43 (방어형) | **낚시**: 희귀 물고기 확률 2배, 물뿌리개 무료 |
| 🔥 **모락** | 불꽃 귀 토끼 | 불 | 39 / 52 / 43 / 65 (속공형) | **채광**: 광석 +1, 곡괭이 에너지 절약 |

상성: 풀 → 물 → 불 → 풀 (+ 땅·바람·빛·노말). 그 밖에 야생 루미 10종(콩콩·포르르·포실·자갈·퐁퐁·반짝·부싯·말랑·이끼곰, 밤에만 드물게 나오는 **아스트라**).

### 시스템
- **야생 조우**: 1번 도로 풀숲을 걸으면 일정 확률로 배틀(밤엔 출현표가 바뀜). 낚시 중에도 물 속 루미가 걸릴 수 있음
- **턴제 배틀**: 싸우기(기술 4개, 속성 일치 보너스·상성·급소·능력 랭크) / 가방(별빛 병·회복 꿀) / 루미 교체 / 도망. 경험치·레벨업·새 기술 습득
- **포획**: 별빛 병(상점 구매) — 체력이 낮을수록 잘 잡힘, 병 흔들림 연출. 파티 6마리 초과분은 보관함으로
- **트레이너**: 시야에 들어가면 `!` 후 다가와 말을 걸고 승부. 승리 시 상금, 바람골 도장 관장 **세나**를 이기면 바람 배지
- **파트너 동행**: 맨 앞 루미가 플레이어를 따라다니며 속성별 일을 도와줌 (위 표 + 채집 2배·에너지 절약·경험치 1.25배 등)
- **채광·채집·낚시**: 곡괭이로 채석장 광석(돌·구리·철·별조각), 길가 열매·버섯·약초 채집, 낚싯대(물가에서 사용 → `!` 뜨면 Space)
- **회복**: 마을회관 박사 / 바람골 루미 센터. 전부 쓰러지면 농장으로 돌아가고 골드 10%를 잃음
- 배틀·포획·보상은 모두 **서버 권한**(`shared/sim/Battle.ts`)으로 계산 — 멀티플레이에서도 조작 불가, 다른 유저의 파트너도 보이고 배틀 중이면 머리 위에 표시

- **이동**: 맵 가장자리 길 · 동굴 입구 · 층 계단 · 정기선 부두(섬) · 건물 문 · 차원문. 생성 시 모든 워프 대상 맵·스폰이 있는지, 모든 출입구가 걸어서 닿는지 검사합니다
- **배지 8개**가 있어야 루미 리그 · 태초의 방 · 뒤집힌 세계에 들어갈 수 있고, 사천왕 → 챔피언은 순서대로만 도전할 수 있습니다

- **휴대폰 지도(M)**: 지방 전체 지도. 가 본 곳 주변만 안개가 걷히고(저장됨), 마을/장소 수를 셉니다

## 현재 구현된 것

- **별빛 마을 (60×44)**: 농장 오른쪽 길 끝에서 마을로 이동(페이드 전환 + 지역 이름 배너). 가운데 호수(오리·부두), 둘레 돌길 광장, 잡화점·카페·마을회관·대장간·주택 5채, 시장 가판대, 게시판, 벤치, 가로등
- **NPC 10명**: 기존 5명 + 오 촌장·루나(카페)·태오(악사)·미오(화가)·도윤(우체부). 스케줄에 따라 농장↔마을을 실제로 걸어서 오가고, 밤엔 집으로 들어감
- **상점**: 잡화점(씨앗)·카페(커피/빵/케이크 = 에너지 회복)·가판대. 영업시간과 주인 위치 확인, 구매는 서버가 골드·가방 공간 검증
- **멀티플레이 확장**: 같은 맵에 있는 모든 접속자 표시(이름표 + 보간 이동), 접속자 목록(Tab, 누가 농장/마을에 있는지), 채팅 로그 + 머리 위 말풍선

- **농장 맵 (56×42 타일)**: 듀얼그리드 오토타일(잔디/흙길/물가), 애니메이션 물, 연못과 부두, 개울, 울타리 친 밭, 숲 테두리, 꽃·자갈 장식
- **Y-Sort 깊이 정렬**: 캐릭터·나무·건물이 발 위치 기준으로 자연스럽게 겹침, 나무/집 뒤로 가면 반투명 처리
- **플레이어**: 4방향 × `idle`(숨쉬기+눈 깜빡임) · `walk` · `run` · `hoe`(괭이질) · `axe`(도끼질) · `water`(물주기) · `interact`(상호작용) 애니메이션, 축 분리 AABB 충돌 + 모서리 미끄러짐 보정
- **NPC 5명** (하나·민수·소라·박 영감·준이): 시간대별 스케줄 → A* 길찾기 → 서 있기/배회/작업/퇴장, 말 걸면 플레이어 쪽을 보고 대화(초상화·타자기 효과·호감도 하트), 접근 시 말풍선
- **농사 루프**: 괭이질 → 씨앗 → 물주기 → 다음 날 성장 → 수확 → 출하 상자 → 아침 정산, 재수확 작물(토마토), 비 오는 날 자동 물주기
- **시간/날씨**: 실제 7초 = 게임 10분, 새벽·한낮·노을·밤 색감 변화, 밤에 가로등·창문 발광과 반딧불, 굴뚝 연기, 구름 그림자, 비
- **분위기 연출**: 나무/풀 흔들림, 나비, 닭(배회·모이 쪼기·달려오면 도망), 흙먼지·물방울·나뭇조각 파티클
- **DOM 오버레이 UI**: 시계/날짜/날씨/골드 HUD, 에너지 바, 12칸 핫바, 대화창, 토스트, 상호작용 힌트, 타이틀 화면, 하루 전환 화면, 채팅

## 아키텍처 메모

- **서버 권한(Authoritative)**: 클라이언트는 `ActionIntent`(예: `useTool(slot, tx, ty)`)만 보내고, `FarmSimulation`이 거리·에너지·도구 소지를 검증한 뒤 이벤트를 브로드캐스트합니다. 싱글플레이는 같은 시뮬레이션을 브라우저에서 돌리는 `LocalAuthority`를 씁니다 → 씬 코드는 두 모드에서 동일.
- **이동 동기화**: 내 캐릭터는 즉시 로컬 이동(Client-side Prediction), 서버는 속도·충돌 검증 후 이상하면 `correct`로 보정(Reconciliation), 다른 플레이어는 110ms 버퍼 선형 보간(Entity Interpolation).
- **데이터 기반**: 작물/아이템/NPC 대사·스케줄은 `shared/data/*.json`만 고치면 반영됩니다.
- **타일 상태**: `SoilState.Unplowed / Plowed / Watered` + `CropInstance(stage)`.

## 그래픽 재생성

모든 이미지는 `tools/art/*.mjs` 코드로 그려집니다. 색·형태를 바꾸고 다시 생성하세요.

```bash
npm run gen          # = gen:art + gen:map
```

- 루미 디자인: `tools/art/creatures.mjs` (귀·꼬리·무늬 파츠 조합)
- 건물 실내: `tools/art/interior.mjs` 의 `ROOMS` (벽지·바닥·벽 장식·러그·가구 배치를 한 곳에서 → 그림과 맵이 함께 생성)
- 캐릭터 외형: `tools/art/looks.mjs` (머리 스타일 `short|long|bob|bun|ponytail|spiky|bald`, 의상 `shirt|overalls|dress|apron|vest`, 모자 `straw|cap|beanie`, 수염/안경)
- 애니메이션 포즈: `tools/art/char.mjs`의 `ANIMS`
- 맵 레이아웃: `tools/map/generate-map.mjs` (생성된 `farm.json`은 Tiled 에디터로 열 수 있음)
